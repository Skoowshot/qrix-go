# Qrix Runtime (`qrixr`)

**Qrix Runtime** is an extensible, distributed CAS runtime handling content processing and delivery, allowing for 
environment-to-environment communication.

Written as a lightweight core in Go, it handles all the infrastructure work-such as processing raw data into 
structured, binary contents ready for distribution and usage.

The built-in plugin system provides control over the runtime, allowing you to configure content formats, 
their processing, distribution and usage.
